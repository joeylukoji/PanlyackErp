# Workspace design contract

Mode: Operate. Primary task: review a supplier invoice, then post its effects with confidence.

THESIS: a document desk with explicit approval; financial data stays readable and traceable.
OWN-WORLD: slate navigation, pale neutral work surface, dark green actions, amber review states, system UI type, tabular amounts, restrained borders.
STORY: upload, inspect the original, correct extracted lines and payments, confirm, post, inspect the resulting ledger and balances.
FIRST VIEWPORT: compact navigation at left, page title and primary action above a wide work area. Review uses a document preview and editable details; small screens stack these sections.
FORM: task-led workspace from the blueprint. Impeccable concept-seed was attempted but its engine failed to initialize; seed: none (unavailable).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

No image assets are needed. Empty states explain the next action. Never fabricate charts or transactions. Browser inspection must cover desktop and mobile.
