# PanlyackERP workspace

Mode: Operate. A daily document-review workspace, not a marketing page.

The desktop shell uses a 244px deep teal navigation rail with consistent line icons, compact organization bar, pale mineral work surface and crisp white ledger panels. On phones a sticky brand bar opens a full-height navigation drawer with a backdrop and close control. Green identifies actions and posted state, blue identifies confirmed state, amber marks review/demo notices, and red is reserved for actionable errors.

Aptos/Segoe UI keeps dense forms familiar. Amounts use tabular numerals. Table headers are quiet, row separators aid scanning, and activity values align across a two-column ledger. Tables scroll inside their container; forms stack below 760px; document preview stacks above review below 1150px. Focus has a distinct blue outline. Inputs have labels, errors use alerts and posting success uses a status region.

The signature interaction is the document-to-ledger path: original document alongside editable extraction, explicit confirmation, then atomic posting and visible balances. Posted forms are disabled. The dashboard opens with a photographic document-and-stock scene and a real invoice-import action. The local owner login uses a split composition: a quiet form and a photographic worktable panel describing the real import, review and posting steps. On phones that image becomes a compact banner above the form. Motion is limited to the navigation drawer, one photo arrival and a dashboard-image hover response; reduced-motion preferences suppress spatial movement. No decorative charts, invented prices or fabricated activity are shown. The React pricing reference was used only as visual context because this product has no defined plans or prices.

The two project-owned photographs were generated for this interface and compressed to JPEG. The invoice PNG remains labeled synthetic test data.
