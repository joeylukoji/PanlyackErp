# PanlyackERP workspace

Mode: Operate. A daily document-review workspace, not a marketing page.

The desktop shell uses a 220px slate navigation rail, a compact white organization bar and a pale work surface. Mobile turns navigation into a horizontally scrollable row. Dark green identifies actions, amber marks review/demo notices, and red is reserved for actionable errors.

System UI typography keeps forms familiar. Amounts use tabular numerals. Tables scroll inside their container; forms stack below 720px; document preview stacks above review below 1100px. Focus has a distinct blue outline. Inputs have labels, errors use alerts and posting success uses a status region.

The signature interaction is the document-to-ledger path: original document alongside editable extraction, explicit confirmation, then atomic posting and visible balances. Posted forms are disabled. No decorative charts or fabricated activity are shown.

Verified on 1440px desktop and 390px mobile, plus the app's initial narrow viewport. Impeccable detector returned an empty finding list. No decorative raster assets ship; the invoice PNG is labeled synthetic test data.
