# PanlyackERP workspace

Mode: Operate. A daily document-review workspace, not a marketing page.

The desktop shell uses a 244px deep teal navigation rail, compact organization bar, pale mineral work surface and crisp white ledger panels. Mobile turns navigation into a horizontally scrollable row. Green identifies actions and posted state, blue identifies confirmed state, amber marks review/demo notices, and red is reserved for actionable errors.

Aptos/Segoe UI keeps dense forms familiar. Amounts use tabular numerals. Table headers are quiet, row separators aid scanning, and activity values align across a two-column ledger. Tables scroll inside their container; forms stack below 760px; document preview stacks above review below 1150px. Focus has a distinct blue outline. Inputs have labels, errors use alerts and posting success uses a status region.

The signature interaction is the document-to-ledger path: original document alongside editable extraction, explicit confirmation, then atomic posting and visible balances. Posted forms are disabled. The local owner login uses a split composition: a quiet form and a deep teal panel describing the real import, review and posting steps. No decorative charts, invented prices or fabricated activity are shown. The React pricing reference was used only as visual context because this product has no defined plans or prices.

Verified on 1440px desktop and 390px mobile for the local login and workspace. No decorative raster assets ship; the invoice PNG is labeled synthetic test data.
